# te_predictor
Python code and data for predicting thermoelectric properties of light lanthanide elements doped ATiO3 (A = Ca, Sr, Ba)
### 1. Installation (Optional if already done)
Before running the code, make sure you have the required packages installed by running:
pip install numpy pandas matplotlib seaborn scipy optuna scikit-learn xgboost torch matminer pymatgen shap

### 2. Running the script
Place thermoelectric_predictor.py and data.csv in the same folder/directory, then run:
python3 thermoelectric_predictor.py

### 3. When the code is succesfully finished running, you should see:
✅ Analysis complete. Results saved in 'results/' and 'figures/'.
